# Step 10J — Core / Models / My Models Gallery Split

The Studio Model Gallery is now separated into three concise views:

- **Core** — foundational Machine Learning, Deep Learning, and Signal Processing study models.
- **Models** — complete architecture families: Language, Vision, Audio, JEPA, Multimodal, and State & Memory.
- **My Models** — user-saved models only.

Signal JEPA remains under JEPA, while SOUP Signal is moved to State & Memory so the Core signal area stays focused on foundational signal-processing models.

The change is applied to both editable frontend source and the packaged Studio builder asset.
